Movie Ticket Booking System (Python CLI)
A lightweight command-line interface (CLI) application written in Python that simulates an interactive movie ticket booking experience. It guides users through age verification, genre/movie selection, seat pricing, eligibility for promotional offers, payment verification, and customer loyalty classification.

🛠️ Features
Age Verification: Restricts access to users 18 and older.

Genre & Movie Selection: Allows browsing across Action, Comedy, and Horror genres.

Tiered Seat Pricing: Supports Silver (₹200), Gold (₹300), and Platinum (₹500) tiers.

Automated Rewards: Triggers a free popcorn perk for Platinum bookings (₹500+).

Payment Processing: Verifies completed transactions before finalizing bookings.

Loyalty Program: Identifies repeat visitors (>5 visits) as VIP Customers.
